# Premium storefront homepage

Redesign of the homepage shown in the reference screenshot (the root URL, not the marketplace results page).

- Search-led header with accessible account/order controls and category navigation.
- Editorial forest-green hero with real catalogue products. Prefer different shops in the three hero slots, then fill remaining slots from available images. Handle zero, one and two-image catalogues.
- Visual category links, eight product cards with real prices and conditional verified-seller labels, shop discovery, seller onboarding, HUNT and support/legal links.
- Theme-aware surfaces, reduced-motion styling, keyboard focus and responsive layouts.

Local browser verification used the restored isolated database: desktop light/dark appearance, 390px and 320px widths without horizontal overflow, loaded product imagery, search for polo, and category navigation. No orders, payments, customer messages or production data edits were made. The buyer-results page is unchanged.
